# 诊断规范草案

错误信息必须指向源码位置、说明原因，并在可行时给出修复建议。诊断编号一旦发布，后续只追加不复用。

| 编号 | 类别 | 示例 |
| --- | --- | --- |
| VYR-1000 | 词法错误 | 不支持的字符或未结束字符串 |
| VYR-1100 | 缩进错误 | 缩进不是 4 的倍数，或混用了 Tab |
| VYR-2000 | 语法错误 | 期待表达式、缺少函数返回类型 |
| VYR-2100 | 变量错误 | 未定义变量、给 `let` 重新赋值 |
| VYR-3000 | 类型错误 | `if` 条件不是 `bool` |
| VYR-3100 | 宿主契约错误 | `Order` 没有属性 `amout` |
| VYR-3200 | 能力错误 | 未注册查询或命令 |
| VYR-4000 | 运行时错误 | 宿主能力返回错误或命令计划失败 |

诊断至少包含：编号、消息、源码文件、起止位置。实现阶段应为每个编号编写正例和反例测试。
