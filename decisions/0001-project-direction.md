# ADR-0001：项目方向

- 状态：接受
- 日期：2026-09-28

## 决策

Veyra 定位为嵌入 Java 应用的静态业务脚本语言，而不是新的通用编程语言或 JDK 的一部分。其核心机制是：在脚本加载/编译阶段，依据 Java 宿主显式提供的契约检查数据属性、查询能力和业务命令。

## 背景

Java 应用经常需要把频繁变化的业务规则独立出来，以便热更新、审计和按业务场景调整。动态规则引擎通常把字段错误和参数错误推迟到运行时，而直接使用 Java 又会让每次规则变化都进入应用发布流程。

## 取舍

Veyra 不试图解决所有编程语言问题，也不接管领域模型、事务或分布式一致性。它牺牲通用性和任意 Java 调用能力，换取可检查的宿主契约、受控能力边界和规则代码的独立更新。

## 影响

- 实现优先级是 Java API、前端、契约检查和解释执行。
- `.veyra` 是源码载体，不要求生产规则一定来自文件，也可以来自数据库或配置中心。
- IDE 插件、CLI、字节码后端属于后续工具和性能工作，不能反向决定语言语义。
